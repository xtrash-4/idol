Pengaturan Groq API Key

Cara Dapatkan Groq API Key 100% GRATIS:
  1. Buka console.groq.com/keys
  2. Login dengan akun Google / GitHub (Tanpa Kartu Kredit).
  3. Klik tombol "Create API Key".
  4. Salin kuncinya (berawalan gsk_...) dan tempel di bawah ini.

API Key disimpan aman hanya di memori browser lokal (localStorage) Anda.

Daftar model akan disesuaikan otomatis dengan model yang tersedia untuk API key Anda.
